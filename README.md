# Healthcare IT Homelab

A self hosted healthcare IT environment designed to explore Electronic Health Records (EHR), medical imaging, healthcare interoperability, and clinical application infrastructure.

This project serves as a hands on learning environment for healthcare IT administration and application support, with a focus on technologies used in modern healthcare organizations.

## Project Objectives

- Deploy and administer an open source Electronic Health Record (EHR).
- Build a Picture Archiving and Communication System (PACS).
- Explore DICOM medical imaging standards and workflows.
- Implement HL7 FHIR interoperability and API integrations.
- Develop automated healthcare workflows.
- Practice Linux administration, virtualization, networking, and security.
- Document technical implementations and troubleshooting.

## Project Architecture

The environment will consist of two primary components:

**Clinical Systems**
- Electronic Health Records
- Patient management
- Clinical encounters
- Healthcare interoperability

**Medical Imaging**
- PACS infrastructure
- DICOM storage and retrieval
- Medical imaging visualization
- Imaging workflow integration

## Infrastructure

The environment will be hosted on a self-managed Proxmox virtualization server using isolated Linux containers and Docker services.
